в методе rnis_subscribe_update контроллера app/Http/Controllers/RnisSubscribeController.php реализуй следующую логику:

1. В метод приходит реквест в котором будут следующие поля
    - truc_number
    - end_subscribe
    - token

2. В методе проводится каскад проверок каждая из которых прирывает выполнение метода:
    - проверка токена токен сравнивается с захардкоженной последовательностью символов если не совпадают метод завершается с ошибкой 403 в которой будет комментарий отказанно в доступе
    - В таблице car_numbers ищется первый элемент у которого truc_number = переданному в метод параметру. Если ничего не нашлось то возврящается подходящий код ошибки с комментарием "ГРЗ не найден в базе"
    - у найденного на предедущем шаге элемента считываются подписки по связи rnis_subscribe. Если среди них есть элемент с датой совпадающей с переданной в метод мы обновляем элемент, если нет то создаем новый. и возвращаем код 200 с сообщением - данные обновлены
